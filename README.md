# FreeTalk

자유롭게 영어로 말해 보는 회화 연습 챗봇입니다. 친구, 선생님, 면접관 중에서 상대를 고르고, 일상·취미·음식 같은 주제로 대화를 이어갑니다.

답변은 OpenAI가 만들고, API 키는 브라우저에 전달되지 않습니다. 로컬 서버가 `.env`의 키를 읽어 대신 요청합니다.

## 실행

1. 프로젝트 폴더에 `.env` 파일을 만들고 키를 넣습니다.

   ```
   OPENAI_API_KEY=sk-...
   ```

2. `start.bat`을 더블클릭합니다.
3. 열리는 주소로 접속합니다. 기본 주소는 http://127.0.0.1:8765/ 입니다. 그 포트가 사용 중이면 8766, 그다음 8770을 사용합니다.

`index.html`만 열면 키를 읽지 못합니다. 그때는 페이지 안의 기본 연습 답변만 나옵니다.

OpenAI 계정에 크레딧이 있어야 실제 대화가 연결됩니다. 크레딧이 없으면 화면에서 안내하고, 기본 연습 답변으로 이어갑니다.

## 대화

- **친구**: 편하게 수다
- **선생님**: 어색한 문장을 더 자연스럽게 다듬어 카드로 보여 줌
- **면접관**: 카페 회사 면접 연습
- **난이도**: 초급, 중급, 고급
- **주제**: 일상, 취미, 음식, 여행, 영화·음악, 일·공부, 주말, 꿈

Enter로 메시지를 보냅니다. Shift+Enter는 줄바꿈입니다. 추천 문장을 누르면 입력창에 들어가고, 고친 다음 보낼 수 있습니다. 마이크 입력과 목소리 듣기는 Chrome에서 가장 잘 됩니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 대화 화면 |
| `server.ps1` | 페이지를 열고 OpenAI에 대화를 전달하는 로컬 서버 |
| `start.bat` | 서버 실행 |
| `.env` | API 키. Git에는 올라가지 않습니다. |
